# 진행 구조 (Progression)

## 1. 서사 ↔ 메카닉

플레이어는 상단(商團)을 운영하는 거상이 되는 게 목표. 한 런은 상단의 **확장 여정**.

| 챕터 | 활동 범위 | 서사 위험 | 메카닉 위험 |
|---|---|---|---|
| Chapter 1 | 마을 → 마을 | 산적, 야수, 강도 | 약한 적, 적은 시너지 |
| Chapter 2 | 도시 → 도시 | 조직 범죄, 라이벌 상단, 도적단 | 중간 강도 적, 시너지 보유 |
| Chapter 3 | 국가 → 국가 | 국경 전쟁, 정규군 충돌, 보스 적 | 강력한 적, 시너지 풀 가동 |

→ **거리·위험도가 챕터마다 다른 게 난이도 곡선의 서사적 명분.**

## 2. 계층 구조

```
Run
└─ Chapter (3개: 마을 / 도시 / 국가)
   └─ Stage (챕터 내 노드들)
      └─ Event (노드 도착 시 실제 콘텐츠)
```

### 이벤트 종류
- **적 직면 (Battle)** — 일반 전투. 가장 흔한 노드.
- **여관 (Inn)** — 부상 치료(저렴), HP 회복, 소규모 보급.
- **미니보스 (Mini-boss)** — 엘리트 전투. 보상 강함.
- **특수 이벤트 (Event)** — 텍스트 기반 선택지. 위험·보상 트레이드오프.

### 챕터 종료
- 각 챕터 끝에 **챕터 보스** 노드 (확정 보스, fog of war 적용 X).
- 보스 처치 시 다음 챕터의 시작 도시/마을로 진입.
- 챕터 사이에 **거래 화면**(도착 도시) — 카고 아이템 판매, 새 유닛/아이템 구매, 부상자 치료, 사망자 부활.

## 3. Fog of War

> 사용자 요청: 이벤트는 직접 겪기 전까지 MAP에서 알 수 없음.

### 데이터 모델
- `MapNode.kind`는 항상 존재(생성 시 결정).
- `RunState`에 `revealed_nodes: Array[int]` 추가.
- UI는 `revealed_nodes`에 있는 노드만 종류 아이콘 표시, 나머지는 `???`.

### 공개 시점 옵션 (현재 미결정)
- **(A) 도착 시만 공개**: 진입할 때까지 모름. 가장 강한 fog. 정찰 아이템이 의미 있음.
- **(B) 인접 노드 미리 공개**: 한 스텝 앞은 보임. StS의 중간 절충.
- **(C) 챕터 입장 시 미니맵 전체 공개**: 노드 종류는 보이지만 적 구성은 모름. Fog 약함.

**기본값**: (A). 정찰 도구(아이템/특수 이벤트로 인접 N개 공개)를 게임플레이 자원으로 만들 수 있음.

### 항상 보이는 것
- 노드의 **위치**와 **연결 관계**(어디로 갈 수 있는지)는 항상 공개. 종류만 숨김.
- 챕터 보스 위치도 공개(목적지로 기능).

## 4. 난이도 곡선

### 공식

```
적 스탯 = 베이스 적 스탯
       × Chapter_Multiplier
       × (1 + StageProgress × StageScale)
       × EventTypeModifier
```

| 변수 | 값 | 비고 |
|---|---|---|
| `Chapter_Multiplier` (C1/C2/C3) | 1.0 / 1.6 / 2.8 | 챕터 점프가 가장 큰 난이도 변화 |
| `StageProgress` | 챕터 내 0~1 정규화 | 첫 스테이지=0, 마지막=1 |
| `StageScale` | 0.5 | 챕터 내 50% 추가 변동폭 |
| `EventTypeModifier` | Battle=1.0 / Mini-boss=1.5 / Chapter Boss=2.2 | 이벤트 종류별 가중 |

### 종합 곡선 (예시 스칼라)

| 위치 | 배수 |
|---|---|
| C1 시작 일반전투 | 1.00 |
| C1 끝 일반전투 | 1.50 |
| C1 챕터 보스 | 1.50 × 2.2 = 3.30 |
| C2 시작 일반전투 | 1.60 |
| C2 미니보스 | (1.60~2.40) × 1.5 |
| C2 끝 일반전투 | 2.40 |
| C2 챕터 보스 | 2.40 × 2.2 = 5.28 |
| C3 시작 일반전투 | 2.80 |
| C3 끝 일반전투 | 4.20 |
| C3 챕터 보스 (= 최종 보스) | 4.20 × 2.2 = 9.24 |

### 단순 스탯 배수만으론 부족함
배수만 올리면 후반이 "그냥 HP 두꺼운 적"이 됨. 챕터 진행할 때마다 **질적 변화**도 같이 추가해야 체감 난이도가 살아남:

| 챕터 | 신규 적 능력 |
|---|---|
| C1 | 단순 추적·근접 |
| C2 | 원거리 적, 그룹 전술, 적 일부가 자체 시너지 보유 |
| C3 | 적 보드 전체 시너지 가동, 특수 능력(소환, 폭발, 디버프) |

### 플레이어 측 스케일링
플레이어 유닛 베이스 스탯은 챕터 배수의 영향을 받지 않음. 플레이어의 성장은:
- 새 유닛 영입(시너지 옵션 확장)
- 적재 그리드 확장(아이템 수용량 ↑)
- 아이템 등급 상승(C2부터 중급, C3부터 고급 아이템 풀)
- 시너지 룰 추가/강화(이벤트·아이템으로 한 런 한정 부여)

## 5. 챕터당 스테이지 수 (제안)

| 챕터 | 스테이지 수 | 비고 |
|---|---|---|
| Chapter 1 | 8 | 짧고 빠르게, 시스템 익숙해지는 구간 |
| Chapter 2 | 10 | 본격 전략 구간 |
| Chapter 3 | 12 | 결정적 빌드 검증 구간 |

총 30 스테이지 + 챕터 보스 3개 = **약 33개 전투**.

스테이지 = 맵 노드 1개로 1:1 매핑. 한 스테이지에 여러 분기 노드가 같은 깊이에 있다 (StS처럼).

## 6. 거래 시스템 (Option a 채택)

> 거래는 코어 메카닉 아님. 챕터 간 도시 화면에서 일괄 처리.

### 거래 화면 (챕터 종료 후)
- **판매**: 카고에 적재한 아이템을 골드로 환원. 챕터 진행할수록 판매 마진 ↑.
- **구매**: 다음 챕터에서 쓸 아이템·유닛 구입.
- **치료**: 부상 유닛 회복.
- **부활**: 사망 유닛 부활 (고가).
- **카고 확장**: 그리드 업그레이드 구매.

### 도중 보상 (스테이지 노드)
- 전투 승리 → 골드 + 아이템 드랍(카고에 적재).
- 미니보스 → 더 좋은 아이템 + 골드.
- 특수 이벤트 → 골드/아이템/유닛/위험 선택.

### 메인 메카닉은 호위 전투
거상의 거래는 **챕터 보상 정산 + 다음 챕터 준비** 역할만. 거래 자체의 미니게임(시장 가격 변동, 협상)은 도입 X — 게임 코어를 자동전투+시너지에 집중.

## 7. 메타 진행 (Ascension) — 미결정

- StS의 Ascension처럼 완주 시 다음 런이 어려워지는 메타 시스템 도입 의향은 미정.
- 도입한다면 챕터 배수 추가 가산 + 적 능력 강화 모드 추가.
- 1차 출시 후 결정.
