# 게임 Audit — 2026-06-02

UX·재미 요소 관점에서 현 상태를 종합 검증.
관점: **반복성, 의사결정 밀도, 동기 부여, 시각 피드백.**

---

## 1. 현재 게임 루프

```
메인 메뉴 → 새 런 → 거점 →
   [용병 고용 · 상점 · NPC · 맵으로]
   ↓ 맵 진입
   노드 클릭 → [전투/엘리트/쉼터/상점/이벤트/보물/보스]
   ↓ 전투
   PREP(편성) → ITEM_APPLY → BATTLE → RESULT → 맵
   ↓ 보스 승리
   chapter++ → 새 맵 → 거점 (다시)
   ↓ 챕터 3 보스 승리
   GAME CLEAR
```

루프 자체는 **닫혀 있음** — 메인 메뉴부터 게임 클리어까지 동작은 함.
재미는 각 단계 안의 **의사결정 밀도와 시각·청각 피드백**에서 나오는데, 그 두 축에서 갭이 있음.

## 3. 약점 ⚠️

### A. PREP 페이즈가 결정 부족

현재 PREP에서 할 일:
- 보관함에서 유닛 드래그해서 배치
- 끝.

**시너지 미리보기 표시 없음** — 코드(SynergyEngine)에 logic은 있지만 UI 표시는 약함. 사용자가 "이렇게 배치하면 뭐가 좋은지" 즉각 못 알아봄. 그냥 그림이고 결과는 전투 후에 알게 됨.

**개선안**: 시너지 활성 아이콘 + 호버 시 "벤+보병 t3 활성 (atk +10%, hp +12%)" 툴팁. 시너지 패널을 PREP 화면 한 구석에 노출.

### B. ITEM_APPLY가 비어 있음

PREP → ITEM_APPLY → BATTLE 구조인데 ITEM_APPLY는 현재 0.5초 대기만. 카고 아이템이 없어서.

→ "이번 전투에 어떤 아이템 쓸까?" 의사결정 부재 = **소비 vs 보존 긴장 0**.

**개선안**: CargoItem .tres 5-10개 즉시 제작 + 슬롯 3개 UI. **재미 공백 중 가장 큼**.

### C. 상점이 비어 있음

hub의 상점도, 맵 노드의 상점도, 보물도 — CargoItem .tres가 없어서 "구매·획득" 자체가 안 됨. 골드를 가질 의미가 약함.

골드의 현재 용처:
- 용병 고용 (작동)
- 카고 확장 (`CityActions` 있음, UI는 어디?)
- 부활 (대상이 거의 발생 안 함)
- 치료 (쉼터로 무료 회복 가능)

→ **골드가 용병에만 쏠림**. 다양한 사용처 필요.

### D. 퀘스트 보상이 골드만

오늘 만든 퀘스트는 **보상 = 골드**가 전부. 골드의 용처가 좁으니 퀘스트 보상의 매력도 약함.

**개선안**: 보상에 "무작위 카고 아이템 1개" / "카고 슬롯 1열 확장" / "특정 유닛 무료 영입" 추가.

### E. 챕터 차별화 부족

C1 산적 → C2 정규군 → C3 정예 — **데이터로는 진영 정의됨**. 하지만:
- C2/C3 인카운터 .tres 없음 (Tier1 시트만 채워짐)
- C2/C3 적 .tres 없음
- 챕터 진행 시 시각·텍스트 변화 없음 (story_screen 한 번만 나오는 인트로)

→ "다음 챕터로 가는 보람"이 약함. 같은 적과 다시 싸우는 느낌.

### F. 유닛 영구 사망의 무게 부족

HP carry over 시스템은 있는데:
- 사망 시 부활 비용 (`REVIVE_COST_BY_CHAPTER`) = 80/200/500 G
- 그런데 도시 신전(부활 가능 위치)이 hub_screen에 없음
- 그래서 사망자가 사실상 **영구 손실** (의도? 의도면 OK)

→ 신전 UI 없으면 부활 시스템이 죽은 코드.

### G. 시너지 발동 시 시각 피드백 없음

전투 중 GLOBAL_TRAIT나 BOSS_AURA가 발동해도 화면에 표시 X. 사용자가 "산적단 무리 발동!" 같은 정보 못 받음.

오토배틀러에서 시너지 발동 알림은 **핵심 dopamine 트리거**.

### H. 결과 화면이 단조로움

전투 결과 화면(RESULT_SCREEN) 현재 구성:
- 골드 보상 표시
- 부상자 표시
- "계속" 버튼

→ 가장 흥분되는 순간(승리)에 정보가 빈약. **MVP·뛰어난 활약·총 데미지·시너지 발동 횟수** 같은 통계 없음. 다음 전투 동기 부여 약함.

## 4. 동기 부여 요소

### Pull (당기는 힘)

| 요소 | 강도 |
|---|---|
| 빌드 실험 (시너지 조합) | 강 |
| 챕터 클리어 (3 챕터) | 중 |

| 새 챕터 풍경·적 | 약 (변화 적음) |

### Push (피해야 할 위협)

| 요소 | 강도 |
|---|---|
| 게임 오버 (패배 시 런 종료) | 강 |
| 부상 누적 → 사망 | 중 |

| 카고 공간 부족 | 0 (아이템 없음) |
| 시간 캡 (120초 무승부) | 약 |

## 6. 1주일 안의 "재미 부스트" 추천 패키지

**A. 카고 콘텐츠 부트스트랩** (CargoItem 10-15개 + 슬롯 UI 구현) — 게임의 핵심 메카닉 중 하나가 살아남.

**B. 결과 화면 통계** — "벤 보병 군인이 73 데미지로 MVP / 산적단 무리 시너지 3회 발동 / 사거리 안 적중률 92%" — 다음 전투 의욕.

**C. 퀘스트 보상에 카고 아이템 추가** — 골드 외 보상 매력.

이 3개만 해도 게임이 "한 번 더 돌리고 싶다"로 바뀜.

## 7. 메타 관찰

- **시스템 골격은 매우 견고**: auto-chess + 시너지 + 진영 + 인카운터 + 카고 + 부상 + 퀘스트 + Save/Load 등 거의 다 구현됨.
- **콘텐츠 부족이 재미를 가두고 있음**: 시트의 mock/빈 데이터들이 게임을 "기능 구현 데모"에 머물게 함.
- **시각 피드백 부족이 도파민 차단**: 시너지 발동·MVP·연승 같은 보상 신호가 약함.

## 8. 결론

기술적으론 출시 가능한 수준이지만, **재미 요소는 "구현됨 but 발현 안 됨" 상태**.

가장 빠른 임팩트:
1. **CargoItem 10개를 시트에 채워 넣기 → 상점·보물·이벤트 모두 살아남**
2. **결과 화면에 통계 패널 추가 → 매 전투가 의미 있어짐**

이 둘이 합쳐지면 게임 첫 인상이 완전히 달라짐.
