## 3. 결정 / 합의 사항

### 배틀 시스템 기획 라운드 1-6 (총 합의)

상세 표는 `docs/NEXT-SESSION.md` 합의 표 / `docs/design/battle-flow.md` §0 참조.

**R1 편성 UX** — 5×3 마주보기, 보드 영구, 보관함 사이드 패널 토글, 시너지 실시간, 같은 유닛 두 번 OK, 사망 버리기 쉼터 한정

**R5 적 시스템** — EnemyUnitData 별도, 5개 적 시너지 패턴 모두 채택 (GLOBAL_TRAIT/BOSS_AURA/DEATH_TRIGGER/HP_THRESHOLD/NUMBER_ADVANTAGE), 카탈로그+변동, power 자동, 적도 시너지 받음. 실제 진영·유닛 카탈로그는 추후 전달 → mock 사용

**R4 전투 결과** — 패배=게임오버, HP carry over (유닛 영구 자원), 무승부 캡 120초, 골드=`power×0.25`, 보스 ×2, 쉼터 풀 회복, 부상 회복 100% HP

**R2 아이템 사용** — 전투 직전 일괄 적용, 슬롯 3개, 같은 effect_type max만, 사용=카고 즉시 회수, 적 시너지 비표시, 취소 자유

**R3 연출** — 별도 페이즈, 1×/2× 배속, 일시정지 OK, HP바·데미지숫자=Settings, 페이드 사망, 시너지 아이콘 항상 노출, 도주 X, 결과 슬로우모션

**R6 데이터 모델** — OwnedUnit/BattleResult/ItemEffect/Settings 1차 작성 완료, 기존 클래스 마이그레이션 청사진은 battle-flow.md §6
