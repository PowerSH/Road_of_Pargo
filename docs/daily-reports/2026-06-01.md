### 전투 변수 8종 추가 (Combat Stats v2)

기존 5개(`max_hp, attack, attack_speed, attack_range, move_speed`)에 **8개 추가** — 직업 차별화·전술 깊이.

| 변수 | 기본값 | 효과 |
|---|---|---|
| `defense` | 0.0 | 받는 데미지 (1 - defense) 배 (캡 0.95) |
| `crit_chance` | 0.0 | 크리 확률 |
| `crit_multiplier` | 1.5 | 크리 시 배율 |
| `armor_penetration` | 0.0 | 대상 defense × (1 - 관통) |
| `lifesteal` | 0.0 | 가한 데미지 × N 자기 회복 |
| `hp_regen` | 0.0 | 초당 HP 회복 (절대값) |
| `accuracy` | 0.0 | 분산 축소율 |
| `attack_variance_pct` | **0.20** | 기본 분산 폭 |

기존 모든 유닛에 `attack_variance_pct=0.20` (±20% 분산) 일괄 적용 — 즉시 발현되는 유일한 변화. 다른 7 변수는 0 → 디자이너가 직업별로 후속 채움.

**데미지 공식** (attacker가 일괄 산출):
```
raw = attack × random[1-spread, 1+spread]    (spread = variance × (1-accuracy))
if random() < crit_chance: raw *= crit_multiplier
effective_def = target.defense × (1 - armor_penetration)
final = raw × (1 - effective_def)
target.take_damage(final)
lifesteal → self.heal(final × lifesteal)
```

매 틱: `hp_regen > 0 → self.heal(hp_regen × delta)`

**영향 받은 파일 (12개)**:
- 시트 4 시트 (`units_player / units_enemy / synergies_player / synergies_enemy`) — 32 컬럼 추가, 기존 39 + 7 + 28 + 7 행에 기본값 채움
- 데이터 클래스 6종 (`UnitData / EnemyUnitData / ComputedStats / SynergyRule / EnemySynergyRule / ItemEffect`) — 8 필드씩
- `generate_tres.py` — 4 함수 시그니처 확장 + main 4 호출부 갱신
- **71 `.tres` 자동 재생성** (24 유닛 + 28 시너지 + 7 적 + 7 적시너지 + 7 인카운터)
- `CombatUnit` — `_perform_attack` 헬퍼 + `heal` 메서드 + `tick`에 `hp_regen` 적용, `DEFENSE_CAP=0.95` 상수
- `SynergyEngine / EnemySynergyEngine` — 8 추가 누적기 + ComputedStats에 가산 + clamp
- `ItemEffectApplier` — STAT_BOOST와 ENEMY_DEBUFF 모두 v2 변수 처리
- `tools/balance_check.py` — Unit dataclass에 8 필드 추가 + 파싱
- `docs/design/battle-flow.md` — 데미지 공식 + v2 변수 표 추가

### v2 스탯 일괄 채움 (직업 × 유형 × 국가 × 티어)

기본값 0이던 v2 스탯을 직업/유형/국가/티어 조합 공식으로 계산해 24 플레이어 유닛 + 7 적 일괄 채움.

**플레이어 공식**:
```
base = CLASS_BASES[class]                # 보병/창병/궁병/석궁병 베이스
base += TYPE_MODS[type]                  # 군인/모험가/용병 가산
base += NATION_MODS[nation]              # 벤/크렘/아르덴/넬름 가산
base × TIER_SCALE[tier]                  # additive 스탯들 t1=1.0 / t2=1.15 / t3=1.35
variance × TIER_VARIANCE_SCALE[tier]     # variance만 별도 t1=1.0 / t2=0.80 / t3=0.60
→ cap (defense ≤ 0.95 등)
```

**직업 베이스 (가장 두드러진 항목)**:
- 보병: defense 0.15, accuracy 0.30, variance 0.15 (단단·정확)
- 창병: defense 0.10, crit_chance 0.10 (균형)
- 궁병: crit_chance 0.20, crit_mult 1.7, accuracy 0.50 (헤드샷)
- 석궁병: armor_pen 0.30, crit_mult 2.0, variance 0.35 (관통·헤비)

**유형 가산**:
- 군인: +0.07 defense, +0.10 accuracy
- 모험가: +0.7 hp_regen, +0.05 crit_chance
- 용병: +0.12 lifesteal, +0.07 armor_pen

**국가 가산**:
- 벤: +0.05 defense, +0.05 accuracy (정규군)
- 크렘: +0.5 hp_regen, +0.05 accuracy (모험)
- 아르덴: +0.07 crit_chance, +0.15 crit_mult (정예)
- 넬름: +0.08 lifesteal, +0.05 armor_pen (용병국)

**티어 효과 (additive 스탯 ×1.0 / ×1.15 / ×1.35, variance ×1.0 / ×0.80 / ×0.60)**:
- 벤 보병 군인 t3: def 0.365 / acc 0.608 / var 0.09
- 크렘 보병 군인 t1: def 0.22 / acc 0.45 / var 0.15

**적군 공식** (faction + boss):
- bandit: def 0.05 / crit_chance 0.05 / lifesteal 0.05 / armor_pen 0.05 / accuracy 0.20
- beast: def 0.10 / crit_mult 1.7 / hp_regen 0.5 / variance 0.25
- boss 가산: +0.15 def / +0.10 crit_chance / +0.30 crit_mult / +0.3 hp_regen
- 산적 두목(bandit boss): def 0.20 / cc 0.15 / cm 1.8 / hp_regen 0.3
- 알파 늑대(beast boss): def 0.25 / cc 0.15 / cm 2.0 / hp_regen 0.8

## 3. 결정 / 합의 사항

### 시너지 엔진 Tier 치환 (이전 라운드에서 결정, 오늘 인지)
같은 (applies_to_type, requires_adjacent_type) 쌍의 룰이 매칭되면 **min_adjacent 가장 큰 1개만 적용** (TFT 식). 시트 수치는 "이 티어에서의 총 보너스"로 해석. 다른 쌍 사이는 여전히 합산. → `battle-flow.md` / `synergy-axes.md` 갱신 권장 (보너스 합산 룰 변경분).

### 적 인카운터의 power target 5x 상향
실제 플레이어 유닛 카탈로그(power 150-200/명) 기준으로 적 power 목표값 재설정. 적 총 power = 플레이어 빌드의 50-70% 수준.

### Tier 2 시트는 별도 콘텐츠 스코프
`Tier2_sheet.xlsx`는 unit/synergy의 tier 2가 아니라 **별도 데이터 카테고리**:
- `items_cargo` — CargoItem (shape/effect/sell_price)
- `events_special` — 특수 이벤트 (title/body/choice_a-c)
- `story` — 스토리 텍스트 (chapter/body)

별도 스코프라 오늘 자동 채움 보류 — 사용자 디자인 방향 합의 후 진행 예정.
