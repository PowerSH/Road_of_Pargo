## 3. 결정 / 합의 사항

### 시너지 엔진 Tier 치환 (이전 라운드에서 결정, 오늘 인지)
같은 (applies_to_type, requires_adjacent_type) 쌍의 룰이 매칭되면 **min_adjacent 가장 큰 1개만 적용** (TFT 식). 시트 수치는 "이 티어에서의 총 보너스"로 해석. 다른 쌍 사이는 여전히 합산. → `battle-flow.md` / `synergy-axes.md` 갱신 권장 (보너스 합산 룰 변경분).

### 적 인카운터의 power target 5x 상향
실제 플레이어 유닛 카탈로그(power 150-200/명) 기준으로 적 power 목표값 재설정. 적 총 power = 플레이어 빌드의 50-70% 수준.

### Tier 2 시트는 별도 콘텐츠 스코프
`Tier2_sheet.xlsx`는 unit/synergy의 tier 2가 아니라 **별도 데이터 카테고리**:
- `items_cargo` — CargoItem (shape/effect/sell_price)
- `events_special` — 특수 이벤트 (title/body/choice_a-c)
- `story` — 스토리 텍스트 (chapter/body)

별도 스코프라 오늘 자동 채움 보류 — 사용자 디자인 방향 합의 후 진행 예정.

## 4. 현재 환경 메모

- macOS, Godot 미설치 → 에디터 검증 불가
- `.tres` 파일은 텍스트로 생성됨. Godot이 import 시 UID 자동 부여 (현재 일부 파일 UID 미지정 — 무관)
- Python 3 + openpyxl로 데이터 파이프라인 작업
