### 근접 비비기 해결 — CombatUnit 3가지 개선

**진단**: 4 근접 vs 1 적 시나리오에서 4명이 한 점에 몰려 비비는 현상.
원인: 같은 타겟·같은 자연 접근각·약한 분리력·동맹끼리만 분리.

**솔루션 1: 각도 분산** — `_compute_desired_attack_position(target, allies, eff_range)`
- 자기 위치에서 target 향한 자연 접근각을 시작점
- 같은 target을 노리는 동맹들의 점유각을 수집
- `TARGET_RING_MIN_ARC_DEG=60°` 이내 동맹 있으면 ±30°·±60°·±90°·±120° 순으로 빈 각도 탐색
- desired position = target.position + Vector2.from_angle(chosen) × APPROACH_RATIO × eff_range
- MOVE 상태에서 target.position 대신 desired로 이동

**솔루션 2: 타겟 부하 분산** — `_select_target(enemies, allies)`
- `_find_nearest` 폐기, score = `1000 - distance - load × 120` (`TARGET_LOAD_PENALTY=120`)
- 같은 적을 노리는 동맹 1명당 120점 감점 → 자연스러운 1:1 분산
- 4명 vs 3명이면 한 명만 더블링, 나머지 1:1

**솔루션 3: 분리 강화** — `_apply_separation(allies, enemies, delta)`
- 시그니처에 `enemies` 추가 → 동맹 + 적 모두 분리 (적 라인 못 뚫음)
- 단 `target`인 적은 제외 (사거리 끝에서 접촉 가능해야 공격됨)
- `SEPARATION_STRENGTH 120 → 200` (분리력 67% 증가)
- ATTACK 상태에서도 `ATTACK_SEPARATION_FACTOR=0.20` 비율로 약한 분리 → 자리 잡은 후 겹침 미세조정

**기타 변경**:
- 헬퍼 추가: `_angle_diff(a, b)` (`fposmod` 기반 [-π, π] 정규화), `_is_angle_blocked(angle, blocked, min_arc)` — static
- `target.position` 정확히 향하지 않으니 `raw_dist`는 사거리 판정용으로만 유지, 이동 거리는 `desired_dist` 사용
- `sign` 같은 GDScript built-in 이름 회피 (`dir_sign`)
- 각도 탐색 루프 버그 픽스 — 마지막 attempt가 체크 없이 끝나던 문제 수정

## 3. 결정 / 합의 사항

- **MIN_ARC = 60°**: 4명 attacker까지 자연스러운 분산 (이상적 90° 보다 좀 좁아 여유). 5+ 명이면 일부 겹침 발생 가능 — 그때 조정.
- **TARGET_LOAD_PENALTY = 120**: 거리 점수 단위가 px와 같아서 동맹 1명당 120px 감점. 적이 200px 멀어도 부하 0이면 우선됨.
- **ATTACK_SEPARATION_FACTOR = 0.20**: ATTACK 상태에서 분리 효과를 1/5로. 너무 강하면 공격 자세 못 잡고 흔들림.
- **타겟 적은 분리 대상 제외**: 타겟에 너무 가까워 안 닿는 현상 방지. 다른 적은 분리.
