## 7. 발견 이슈 / 권장사항
### 7.1 단독 친화 시너지 미반영 ⚠
`synergy-axes.md §2`의 친화 매트릭스에서 단독 친화는:
- 벤+**군인** (벤만 유일하게 친화)
- 아르덴+**용병** (아르덴만 유일하게 친화)

그런데 현 시너지 룰(`resource/synergies/`)에는 `applies_to_type`이 국가, `requires_adjacent_type`이 **직업**인 룰만 존재. **유형(군인/용병/모험가) 친화 룰은 0개**.

→ 의도된 차별화 포인트가 코드에 미반영. 룰 12개 더 추가 필요 (`vEn+soldier`, `arden+mercenary` 같은 단독 친화 + krem+adventurer, nelm+adventurer 등).

### 7.2 HP 가중치 검토
HP ≥ 180 유닛 (6명) 평균 power **171.7**. 전체 평균과의 격차 비교 시 power 공식의 HP 가중치 0.4가 적절한지 검토 필요.
DPS 기준이라 탱커는 power 점수상 약해 보일 수 있지만 실제 전투에선 적 공격을 흡수해 가치가 크다.

### 7.3 combat-time 시너지 폭주
- **DEATH_TRIGGER** 5중첩 상한: 6명 인카운터에서 5명 사망 후 마지막 적이 +50% 공격력. 스노볼링 의도면 OK, 의도 외라면 cap 낮추거나 % 줄이기.
- **NUMBER_ADVANTAGE**: 적-플레이어 격차 ≥ 2면 발동. 초반 적이 4명, 플레이어 2명이면 즉시 발동. 트리거 격차를 3으로 올리거나 발동 조건에 플레이어 최소 명수 추가 검토.

### 7.4 비용 대비 이상치
- cost 3: **ven_infantry_soldier** (195.6) 가 **krem_archer_adventurer** (140.5)보다 +39% 강함. 같은 비용 내 격차 큼.

### 7.5 시너지 적용 후 적 실효 power
현 인카운터 power는 **시너지 미적용 베이스값** 기준. 실제 전투에선 `en_syn_bandit_horde`(3+ 시 atk +30%) 같은 GLOBAL_TRAIT 발동 시 적 power가 30% 이상 증가.
→ encounters.md §3 target과 실측 비교 시 baseline-only 값임을 명심.

### 7.6 ⚠️ Arden 시너지가 Ven 시너지보다 훨씬 강할 가능성
§3.2의 '총 % 합'은 단순 산술합. 실제 효과는 **곱**이라 비교를 새로 해야 함:

**Ven+보병 t5** — atk +35%, hp +16%. DPS(= atk × as) 효과 = 1.35× = +35%. HP 효과 = 1.16× = +16%.

**Arden+궁병 t4** — atk +20%, as +60%, rng +30%. DPS = 1.20 × 1.60 = **1.92× = +92%**. 사거리 +30%까지 더해 카이팅 강화.

| 그룹 | 시너지 최고 tier 적용 시 실효 DPS 배수 |
|---|---|
| 벤+보병 (t5) | 1.35× (35% ↑) |
| 벤+창병 (t5) | 1.40× (40% ↑) |
| 크렘+보병 (t5) | 1.35× (35% ↑) |
| 넬름+창병 (t5) | 1.40× (40% ↑) |
| **아르덴+궁병 (t4)** | **1.92× (92% ↑)** |
| **아르덴+석궁병 (t4)** | **1.68× (68% ↑)** |
| **크렘+궁병 (t4)** | **1.92× (92% ↑)** |
| **넬름+석궁병 (t4)** | **1.68× (68% ↑)** |

→ **궁병/석궁병 빌드의 DPS 시너지가 보병/창병의 2배 이상**. 원거리 빌드가 명백히 우월. HP 보너스 없는 점은 약점이지만 원거리는 맞을 일이 적어 HP가 덜 중요. **밸런스 핵심 이슈로 검토 필요.**
