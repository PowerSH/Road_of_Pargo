# 세션 보고서: 진행 구조 + 적재/사망 시스템 디자인

- **날짜**: 2026-05-15
- **에이전트**: Claude Code (Opus 4.7, 1M context)
- **작업자**: PowerSH
- **목표**: 게임의 거시 구조(챕터/스테이지/이벤트)와 적재·사망 시스템을 디자인 문서로 확정. 코드 변경 없음 — 콘텐츠 결정 라운드.

---

## 1. 합의된 핵심 컨셉

### 스토리 ↔ 메카닉
- 주인공 = 상단(商團) 운영 거상.
- 한 런 = **마을 → 도시 → 국가** 3챕터 확장 여정.
- 챕터별 위험 격차가 난이도 곡선의 서사적 명분.

### 거래 모델
- 옵션 (b) 채택했지만 **Backpack Hero식 공간 적재로 단순화**.
- 거래 자체는 챕터 사이 도시 화면에서 일괄 처리 — 코어 메카닉은 호위 전투 + 시너지.

### 적재(Cargo) 시스템
- Backpack Hero 영감: 격자 위 점유 모양 배치.
- 회전 허용, 자동 정렬 제공, 적재 격자 ↔ 시너지 5×3 격자는 별개.
- 시체 버리기 = 단순 공간 회수.
- 아이템 전투 사용은 **전투 시작 전 미리 사용**만 (전투 중 발동 X).

### 유닛 사망
- 3상태: 전투가능 / 부상 / 사망.
- 부상은 회복 가능, 회복 후 영구 페널티 없음.
- 부상 → 사망 임계: C1=4, C2=3, C3=2 스테이지.
- 사망 유닛은 시체로 적재 1×2 차지, 도시 신전에서 부활 가능.

## 3. 기존 코드와의 관계

이 디자인은 **현재 코어 코드를 거의 안 건드린다**:

| 코어 | 변경? |
|---|---|
| `SynergyEngine`, `BoardState` | 변경 없음 |
| `CombatManager`, `CombatUnit` 틱 시뮬 | 변경 없음 |
| `MapNode`, `MapGenerator` | `MapNode.kind` 그대로, `RunState`에 `revealed_nodes` 추가만 |
| `RunState` | `owned_units` 타입 변경 + `cargo` 추가 |
| `UnitData` | 변경 없음 (상태는 새 `OwnedUnit` 래퍼가 보유) |

→ 컨텐츠 레이어(소유 유닛 추상화, 카고, 도시 액션)만 추가. 코어 시뮬은 무관.

## 4. 의도적으로 미룬 것

- **유닛 카탈로그** — 사용자가 엑셀로 작성 중. 받아서 `OwnedUnit`/`UnitData` `.tres` 생성.
- **아이템 풀 카탈로그** — 시스템 골격 우선, 콘텐츠는 나중.
- **챕터 보스 디자인** — 콘텐츠 작업.
- **특수 이벤트 풀** — 콘텐츠 작업.
- **메타 진행(Ascension)** — 1차 출시 후 결정.
- **그리드 확장/부활 가격 곡선의 정확한 값** — 골드 경제 안정화 후.

## 5. 다음 세션 권장 작업

1. **유닛 카탈로그 수령 → `.tres` 일괄 생성** (유닛 + 12개 시너지 룰 보너스 수치).
2. **`OwnedUnit` 클래스 구현** — `RunState.owned_units` 타입 마이그레이션.
3. **`CargoState` 기본 모델** — 회전·자동정렬은 다음 단계.
4. **부상 처리 로직** — 전투 종료 시 HP 0 PLAYER 측 유닛을 INJURED로 변환.
5. **헤드리스 시뮬 테스트** — 시너지+전투+사망 흐름이 정상 동작하는지 자동 검증.
